# 교육시설 안전점검 대시보드 — 2026년도 여름철

교육시설통합정보망(교육시설법 제23조) 운영팀이 2026년도 정기점검(여름철) 결과를
교육부·시도교육청·교육지원청 실무자에게 제공하기 위한 단일 파일 대시보드입니다.

## 실행 방법

**`index.html` 을 더블클릭하세요.** 설치·서버·인터넷 연결이 필요 없습니다.

```
safety_dashboard/
├─ index.html          ← 이 파일을 열면 됩니다
├─ dashboard_data.js   ← 사전 집계된 데이터 (2.2MB, 자동 생성)
├─ build_data.py       ← 원본 xlsx → dashboard_data.js 변환기
└─ README.md
```

`index.html` 과 `dashboard_data.js` 는 **같은 폴더에 함께** 있어야 합니다.
두 파일만 압축해 메일·USB로 배포하면 상대방도 그대로 열 수 있습니다.

- 권장 브라우저: Edge, Chrome (최신)
- 폰트는 인터넷이 되면 Plus Jakarta Sans / Outfit 을, 안 되면 맑은 고딕으로
  자동 대체됩니다. 내부망에서도 레이아웃이 깨지지 않습니다.
- 외부 CSS/JS 프레임워크를 쓰지 않으므로 CDN이 차단된 망에서도 정상 동작합니다.

## 데이터 갱신

원본 엑셀이 바뀌면 변환기만 다시 실행하면 됩니다.

```bash
python build_data.py
# 또는 경로를 직접 지정
python build_data.py "D:\경로\safety_data2.xlsx" dashboard_data.js
```

- 기본 원본 경로: `../safety_data1.xlsx`
- **openpyxl·pandas 등 외부 패키지가 필요 없습니다.** 표준 라이브러리(`zipfile` +
  `xml.etree.ElementTree`)만으로 xlsx를 스트리밍 파싱합니다. Python 3.8+ 이면 됩니다.
- 9.7만 행 처리에 약 15초 걸립니다.

원본 컬럼명이 바뀌면 `build_data.py` 상단의 `C_*` 상수(컬럼 인덱스)만 고치면 됩니다.

### 상호작용

**모든 카드가 같은 필터를 공유합니다.** 아래 요소를 클릭하면 대시보드 전체가 그 범위로 좁혀집니다.

- 시도교육청 행, 시설유형 카드, 시설주용도 행, 경과연수 행, 점검방법 행
- 등급 전이 매트릭스의 칸 (예: `B등급 → C등급` 73건)
- 유형×설립 히트맵의 칸
- 정합성 경고 항목 (예: 시설주용도 미기재 17,741건)

선택한 필터는 상단에 칩으로 표시되고 `×` 로 개별 해제할 수 있습니다.
필터 드롭다운은 **현재 조건에서 실제로 존재하는 값만** 건수와 함께 보여주므로
결과가 0건이 되는 막다른 조합이 생기지 않습니다.

모든 수치는 차트 옆에 숫자로도 표기되어 있어 툴팁 없이 읽을 수 있습니다.
막대·칸·행은 키보드 `Tab` 으로 이동하고 `Enter`/`Space` 로 선택됩니다.

### 내보내기

| 버튼 | 산출물 |
|---|---|
| 상단 **CSV 내보내기** | 현재 필터 기준 요약 통계 (등급 분포, 6개 분류축 교차표, 등급 전이, 정합성 항목) |
| 상단 **인쇄 / PDF** | A4 가로. 필터 바·버튼은 인쇄에서 제외 |
| 표 안 **이 표 CSV 저장** | 즉시조치 대상 명단 18개 컬럼 |

CSV는 UTF-8 BOM으로 저장되어 엑셀에서 한글이 깨지지 않고, 쉼표를 포함한
시설명(`"1동,본관동"`)도 RFC 4180 규격으로 인용됩니다.

## 지표 정의

- **C등급 이하** = 금차안전등급 C·D·E의 합. 「시설물의 안전 및 유지관리에 관한 특별법」의
  등급 체계를 따르며 C등급부터 보수·보강 검토 대상입니다.
- **지적률** = 지적사항수 합계 ÷ 점검 시설 수 × 100.
  한 시설에 여러 건이 지적될 수 있어 100%를 넘을 수도 있는 값입니다.
- **경과연수** = 2026 − 사용승인연도. 연도 미기재는 별도 구간으로 분리합니다.
- **등급 하락 / 개선** = 전차·금차 모두 A~E인 시설만 비교합니다.
  전차 `미지정`에서 등급이 부여된 1,326건은 하락·개선 어느 쪽도 아닙니다.
- **즉시조치 검토 대상** = D·E등급(133) ∪ 등급 하락(245) ∪ 지적 5건 이상(37) = 402건.
  세 조건은 겹칠 수 있어 단순 합보다 작습니다.

## 색상 규칙

`stitch_indigo_glass_dashboard/DESIGN.md` 의 Luminous Glass 토큰을 그대로 씁니다.
데이터 색상은 색각이상 시뮬레이션 검증을 통과한 값으로 고정되어 있습니다.

| 용도 | 값 |
|---|---|
| 안전등급 | A `#0a8a5c` · B `#4648d4` · C `#e0a416` · D `#e0384f` · E `#96131a` |
| 위험도 램프 | `#ec9a85` → `#7d1714` (단일 색상, 밝음→어두움) |
| 건수 램프 | `#a5a7ef` → `#252399` |
| 등급 전이 | 하락=위험 램프 / 개선=초록 램프 / 유지=중립 회색 |

등급 색상은 인접 쌍 최소 CVD ΔE 15.5 (기준 8), 램프는 단조 명도·인접 ΔL·명단 대비
검사를 모두 통과했습니다. 등급은 항상 이름 라벨과 함께 표기되므로 색만으로
구분해야 하는 경우가 없습니다.

## 알려진 제약

- **여름철 단일 회차 데이터입니다.** `안전점검연도`·`추진계획명`·`점검시기구분`이 모두
  단일값이라 시계열 비교가 불가능합니다. 겨울철·전년도 데이터가 축적되면
  등급 전이가 추세로 확장됩니다.
- 정합성 경고의 `등급·지적 불일치`(A·B등급인데 지적 3건 이상)는 **입력 오류 후보를
  넓게 잡은 지표**입니다. 실제 오류인지는 원본 점검조서 확인이 필요합니다.
- `교육부` 항목은 국립대학·부속기관 직속 시설 14,569건으로, 시도교육청과 성격이
  달라 비교 시 유의해야 합니다.

## 후속 확장 후보

- **시군구 지도**: 원본에 `행정시도`·`행정시군구`가 있어 코로플레스 추가 가능
  (행정경계 TopoJSON 내장 필요)
- **권한별 기본 뷰**: `?office=서울특별시남부교육지원청` 형태의 URL 파라미터로
  관할 구역만 기본 노출 — 통합정보망 SSO 연동 전 단계로 유용
- **정합성 지수의 제도화**: 정합성 경고 7종을 시도별 점수로 환산해 분기 배포하면
  입력 품질이 실제로 개선됩니다. 현재 가장 큰 구조적 이슈는 시도 간
  등급 판정 기준 편차입니다 (전북 C이하 21.96% / 지적률 0.42% vs 인천 C이하 0.14%).
